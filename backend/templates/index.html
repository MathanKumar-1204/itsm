Deploying this Flask Backend to Vercel

This backend is pre-configured for Vercel Serverless Python deployment using vercel.json. You can deploy it using the Vercel CLI or by connecting your GitHub repository.

Vercel CLI Command:
vercel --prod
Required Environment Variables in Vercel Project Settings:
MONGO_URI → MongoDB Atlas connection string
MONGO_DB_NAME → itsm_platform
GROQ_API_KEY → Groq GPT-OSS Key
PINECONE_API_KEY → Vector Index API Key
SERVICENOW_INSTANCE_URL → https://dev456763.service-now.com
JWT_SECRET → Secure authentication secret
